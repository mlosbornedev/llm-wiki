## Core Thesis
The deeper shift isn't "AI can make stuff," but that every creative tool is converging on a command line interface, which changes who does what on product teams more than any individual tool.

> "Individual AI creative tools have existed for a while. A connected creative pipeline you can chain together and automate has not."

## Three Tools That Shipped
| Tool | Achievement | Function |
|------|-------------|----------|
| Google Stitch | Redesigned as full vibe design tool | UI/UX design via text prompts |
| Remotion | 150,000+ installs as Claude Code skill | Video generation from text |
| Blender MCP | 17,000 GitHub stars | 3D scene building through conversation |

All three connect through MCP (Model Context Protocol), enabling one pipeline where design flows into code, then video.

## Key Structural Changes
1. The Command Line Changes the Triangle — product-design-engineering dynamic works differently
2. The Markdown File That Matters — DESIGN.md turns individual creative tools into a composable, lossless pipeline
3. The Creative Cron Job — scheduled tasks enable creative pipelines to run while your laptop is closed
