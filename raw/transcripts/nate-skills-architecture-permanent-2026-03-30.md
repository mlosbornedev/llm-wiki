## The Core Problem
Skills have a "Toyota problem" — the workhorse nobody glorifies but that runs the world. Most people still think of skills the way they worked in October (2025): a personal prompting shortcut.

The conventional approach — building a skill that works when you're watching — quietly fails the moment the human leaves the loop.

## Four Changes That Broke the Old Framing
| Change | Impact |
|--------|--------|
| Agents invoke skills | As often as humans do, with no one watching or redirecting |
| Team administration | Admins provision skills across entire organizations with a single upload |
| Cross-industry standard | Adopted by OpenAI, Microsoft, GitHub, and Cursor |
| Platform expansion | Same file now runs in developer terminal, Excel, PowerPoint, and M365 |

500,000 skills now running across platforms interchangeably.

## The Four Prompts
1. **Backlog audit** — Evaluate existing skills for agent-readiness
2. **Output-extraction builder** — Build skills from outputs, not intentions
3. **Agent-readiness stress test** — Test skills without human oversight
4. **Team deployment planner** — Scale skills across organizations

## Key Insight
> "The conventional approach, building a skill that works when you're watching, quietly fails the moment the human leaves the loop."

Old standard: Works when you're at the keyboard with enough judgment to catch output drift.
New standard: Works when agents call it with no one watching and no one to redirect.
