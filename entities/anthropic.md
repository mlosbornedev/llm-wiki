# Anthropic

AI safety and research company led by Dario Amodeu. Building toward becoming an operating system layer for AI — see [[conway]] and [[anthropic-platform-strategy]].

## Two Tracks

### IPO Track (Financial)
See separate section below. Planning $60B+ raise with potential accounting issues around cloud credits.

### Platform Track (Strategic)
Building an always-on agent ecosystem. This is the more consequential story — see [[conway]] and [[anthropic-platform-strategy]].

## IPO Details
- **Planned raise:** $60B+
- **Timeline:** Within 12 months (as of article date ~April 2026)

## Potential Accounting Problem
Anthropic counts certain cloud computing credits from Amazon (its major investor) and Google (its cloud partner) as revenue. Its cloud partners give it computing resources, and Anthropic books the value of those resources as income.

- Bank of America estimates these cloud payments could reach **$1.9B in 2026** and up to **$6.4B by 2027**
- If regulators force Anthropic to change how it reports those numbers before listing, its revenue story shrinks significantly

## Model Pipeline
- **Mythos** — next frontier model, delayed due to security concerns and 10x compute demands (serving would require ~10x more compute than existing infrastructure). Nobody has that compute globally yet.

## Platform Moves (Q1–Q2 2026)
Executed a five-move platform strategy in 90 days — see [[anthropic-platform-strategy]]:
1. Claude Code Channels — neutralized OpenClaw's "message from anywhere" appeal
2. Claude Cowork — enterprise non-technical users, permanent memory leaked
3. Claude Marketplace — enterprise procurement/billing layer
4. Claude Partner Network — $100M, Accenture/Deloitte/Infosys
5. OpenClaw ban — third-party tools blocked, 10-50x price increase for non-approved access
