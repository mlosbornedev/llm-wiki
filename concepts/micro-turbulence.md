# Micro-Turbulence

A term for the permanent condition of continuous rotation: gaps created and destroyed at the speed of model releases. Not a flat, efficient market — a deeply turbulent one, reshuffled with every significant capability step.

## The Old Mental Model (Broken)

Technology arrives → disruption happens → new equilibrium settles.

This is wrong. There is no equilibrium. There is only the **next rotation.**

## The New Mental Model

1. A new capability step opens new gaps (e.g., [[polymarket-bot]] proved speed gaps were exploitable)
2. Gaps compress faster than the last set (Polymarket arbitrage windows: 12.3s in 2024 → 2.7s in early 2026)
3. Each compression opens three new gaps somewhere else
4. The cycle accelerates with each model release

**The meta-game speeds up at the same rate as the games within it.**

## The Velocity Evidence

| Year | Model Release Cadence | Market Absorption Speed |
|---|---|---|
| 2024 | Every few months | ~1 year to fully absorb implications |
| 2025 | ~Quarterly | ~Months to absorb |
| 2026 | Continuous | Markets reprice within hours of leaked draft |

The Mythos leak (March 26, 2026): software sector ETF fell ~3%, Bitcoin tumbled from near $70K to $66K, cybersecurity stocks dropped — all on the **information that the model exists**, before anyone outside a small early-access group had touched it.

## Why This Matters

The Polymarket arbitrage window that produced 98% win rates in late 2025 is already being squeezed. The playbook for "rebuild the bot on the new model" is now a known recipe. When Mythos ships, the same strategy on a better reasoning model gets a temporary edge — until everyone upgrades — then the window compresses again.

**The compression isn't the important part. The rotation is.**

Each model release is a perturbation that opens new gaps across multiple domains simultaneously. Those gaps compress faster than the last set because the adoption infrastructure improves every cycle. But the gaps **never stop opening.**

## The Only Losing Move

Assuming the current state is the steady state.

The conventional treatment of AI disruption as a one-time event is what leads to strategies that defend one position rather than building the capability to find the next gap. See [[upstream-migration]] for where value migrates with each rotation.
