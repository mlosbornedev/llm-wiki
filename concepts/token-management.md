# Token Management

The practice of reducing wasted tokens in AI sessions. Key insight: 66,000 tokens of plugin data loaded before you type anything — making usage limits disappear and costs spiral.

## Core Thesis
> "The models aren't expensive. Your habits are expensive."

Frontier AI properly managed costs pennies. Most people burn 5x, 10x, sometimes 20x on the same work.

## The 66K Token Problem
66,000 tokens of plugin data loaded before user types — hidden consumption most users don't see.

## Token Waste Levels
Four levels from rookie to "advanced" — all fixable behaviors.

## Two Causes of Usage Limit Crises
1. **Real infrastructure strain** — actual capacity limits
2. **Fixable user behavior** — main focus of the article

## Key Metrics
| Scenario | Cost Per User |
|----------|--------------|
| Production pipeline (complex, personalized) | < $0.25 |
| Simple question ("what to have for dinner") | > $0.25 |

## The ChatGPT Migration Problem
Habits from ChatGPT are catastrophically expensive on Claude. Single fix changes everything.

## Key Takeaway
**Token management = AI fluency.** The usage limits dominating AI communities are symptoms of inefficient usage patterns fixable with better habits.
